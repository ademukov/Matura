# Matura — концепт сайта

Концепт сайта ИТ-консалтинговой компании Matura для первых лиц банков и финансовых групп, в том числе выходящих на международные рынки. Тёмная тема, неоновые акценты, анимации на CSS без сборки и зависимостей.

## Что посмотреть

| Файл | Что это |
| --- | --- |
| `index.html` | Главная страница (RU), интерактивный прототип |
| `en/index.html` | Главная страница (EN) — локализация для банков СНГ и Азии |
| `docs/motion.html` | Спецификация анимаций и интерактива по разделам |
| `docs/prompts.html` | Промпты для ИИ-графики (Midjourney / Flux / Recraft) |
| `docs/preview-desktop.png`, `docs/preview-mobile.png` | Полностраничные скриншоты 1440 px и 390 px |

Открыть локально: скачайте репозиторий и откройте `index.html` в браузере.

Опубликовать для коллег: **Settings → Pages → Deploy from a branch → `main` / `(root)`**. Через минуту сайт будет доступен по адресу `https://ademukov.github.io/Matura/`. Страница помечена `noindex`, поисковики её не проиндексируют.

## На что обратить внимание при проверке

1. **Тексты и позиционирование** (RU и EN) — подходят ли формулировки для председателя и членов правления банка.
2. **Порядок практик** — стратегия, международная экспансия, банковские платформы, архитектура, эффективность ИТ-поставки, ИИ.
3. **Кейс филиала в Китае** — согласовано ли упоминание с владельцем проекта.
4. **Цифры** — 35+ экспертов, ~18 лет среднего опыта, 24×7, 3 страны проектов.
5. **Анимации** — первый экран (траектории данных и прогон Playwright), карточки практик, таймлайн кейса, конвейер качества, переключатель форматов работы.

## Известные ограничения прототипа

- Анимация появления блоков при скролле работает на CSS scroll-driven animations (Chrome, Edge); в Safari и Firefox — запасной вариант на IntersectionObserver.
- Форма не отправляет данные.
- Юрлицо и ИНН в подвале — заглушки.
- Счётчики цифр и подсветка за курсором описаны в спецификации, но не реализованы.
- Метрики результатов в кейсах будут добавлены позже.
