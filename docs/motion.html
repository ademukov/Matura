Анимации и интерактив

Движение объясняет, а не украшает: каждый эффект показывает поток данных, порядок шагов или состояние. Всё анимируется только через transform и opacity, петли останавливаются вне экрана.

Символика стекаТраектории = JavaScript, терминал = Playwright

Первый экран показывает то, что мы реально делаем: данные проходят от банковского ядра через интеграции и CI/CD к автотестам, и в прод попадает только сборка, прошедшая контроль качества. Так команда «Эффективность ИТ-поставки» видна уже на первом экране, но не становится главной темой сайта.

Реализация
  • Next.js + React, двуязычность через маршруты /ru и /en
  • Framer Motion — reveal, hover, смена состояний
  • GSAP ScrollTrigger — таймлайн кейса и счётчики, привязанные к скроллу
  • Lenis — плавный скролл; SVG + CSS — траектории (лёгкий вариант)
  • React Three Fiber — 3D-версия первого экрана только для десктопа, ленивая загрузка
  • Бюджет: LCP < 2,5 с, 60 fps, петли на паузе вне экрана

В прототипе reveal при скролле сделан на CSS scroll-driven animations (Chrome, Edge). В Safari и Firefox контент показывается сразу, без анимации появления.
